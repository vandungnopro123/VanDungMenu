VAN DUNG MENU - MA NGUON THEOS

Day la ma nguon tweak iOS arm64, chi tao bong menu noi va bang thong tin demo.
Khong co chuc nang hack game, aim, ESP, bypass hay vo hieu hoa anti-cheat.

Luu y:
- Day la MA NGUON, chua phai file .dylib da bien dich.
- Can may Mac co Xcode va Theos de build.
- Can mot ung dung/qua trinh host phu hop de nap tweak.
- iPhone 7 iOS 15.7 la arm64; viec cai dat con phu thuoc jailbreak va moi truong host.

Build tren Mac:
1. Cai Xcode Command Line Tools va Theos.
2. Mo Terminal trong thu muc VanDungMenu.
3. Chay: make package
4. San pham dong goi nam trong thu muc packages/.

Khong chay lenh build tren dien thoai Android.
